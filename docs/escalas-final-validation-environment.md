## Host, privilégios, seleção e isolamento

- Runtime declarado: Node `>=24.19.0 <25`, npm `>=11 <13`, packageManager npm 11.19.0 (`package.json:6,158–161`). São requisitos, não versões observadas no host. Dependências do lockfile, executáveis locais Prisma/Next/tsx/Playwright e navegador compatível precisam estar disponíveis previamente. Não há npm ci/install explícito no runner; npx ou docker run ainda podem buscar ferramenta/imagem ausente. Ausência deve interromper a execução, sem instalar/puxar por inferência.
- O caminho operacional presume ambiente Unix/Linux: processos detached são encerrados por grupo com PID negativo (`run-isolated-e2e.mjs:181–203`); o segredo do Solver precisa ser legível pelo UID 1001. UID diferente de root/1001 exige sudo não interativo para chown (`:298–299`). Exige acesso ao daemon Docker e imagem de Solver já conferida. Não há prova de compatibilidade direta desse fluxo com PowerShell/Windows.
- Se CI for exatamente true, host/usuário/senha vêm de DATABASE_URL; fora disso, o runner escolhe o primeiro container com labels Compose project=web/service=db e usa seu endereço interno/configuração (`:35–80`). Informar uma URL alternativa fora do ramo CI **não força a escolha desse host alternativo**. CI também afeta retries/reporting do Playwright; não deve ser usado como disfarce de segurança.
- A porta PostgreSQL é preservada da URL ou assume 5432; o nome do banco é substituído. O papel precisa conectar a postgres, criar banco e, no final, terminar conexões daquele banco e removê-lo (`:84–90,317–320,444–450`). Isso requer privilégios adicionais a um usuário de aplicação. A porta 5432 informada como pertencente a outro projeto não é uma opção autorizada.
- App, captura de e-mail, Solver publicado e proxy escutam loopback e usam portas dinâmicas. A porta do app/Solver é reservada e liberada antes do bind definitivo, portanto há uma pequena corrida de alocação; não há prova de porta disponível até a execução. Banco, containers, dist de desenvolvimento e heartbeat têm nomes próprios por execução. O diretório do modelo do Solver é montado somente leitura (`:300–306`).

Encerramento abrupto do processo também não garante finally. Cópias para standalone, cliente gerado e arquivos de predev/seed não são todos revertidos. Não redirecionar TEMP/TMP global nem tratar a existência do finally como dispensa dessa política.
